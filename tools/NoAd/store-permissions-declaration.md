# 应用商店权限声明与上架文案（草案）

> 版本：v1.1（草案，已按 MVP 实现事实修订） ｜ 日期：2026-11-04 ｜ 适用：Chrome Web Store / Firefox Add-ons / Edge Add-ons
> 说明：本文件用于商店提交的「权限理由说明」与「商品描述」，`【待填】` 字段提交前补齐。
> 变更：v1.1 按 `extension/manifest.json` 实际权限修订，补 `<all_urls>` 必需性说明与工程反馈。

## 一、单一用途声明（Single Purpose）
本扩展的唯一用途是：**在用户浏览网页时拦截广告内容（展示广告、弹窗、信息流广告、视频贴片广告）并隐藏相关页面元素**。所有申请的权限均服务于该用途，无其他目的。

## 二、权限清单与用途说明

| 权限 / API | 用途 | 为何必需 | 数据处理 |
|------------|------|----------|----------|
| `declarativeNetRequest` | 基于规则在网络层阻断广告请求 | MV3 下拦截请求的标准机制；不阻断则无法拦截广告资源加载 | 规则在本地匹配，匹配结果不上传 |
| `host_permissions: ["<all_urls>"]` | 在任意站点应用拦截规则并注入隐藏广告元素的内容脚本 | 「全覆盖拦截」定位决定必须覆盖所有站点；`content_scripts.matches` 本身即构成主机权限。Chrome 商店对广告拦截类扩展允许该声明，但需在权限理由中说明 | 仅用于本地匹配与元素隐藏，不读取页面内容用于上传 |
| `webRequest` | 观察被拦截请求的错误事件以统计拦截数 | `onRuleMatchedDebug` 仅 dev 扩展可用，生产需用 `onErrorOccurred` 捕获 `net::ERR_BLOCKED_BY_CLIENT` | 只取「被拦请求域名 + 计数」，不取访问站点、不取完整 URL |
| `storage` | 保存用户设置、白名单、规则缓存、拦截计数 | 保证重启浏览器后设置不丢失、断网时规则仍可用 | 数据仅存本地设备，不上云 |
| `alarms` | 每 24 小时触发规则更新检查与统计上报 | 保证拦截规则保持有效、上报每日一次 | 仅触发规则下载/聚合上报，不含用户数据 |
| `activeTab` | popup 中读取当前标签页域名，供「暂停本域」使用 | 仅在用户点击扩展图标（用户手势）时临时获得当前标签信息 | 不存储、不上报 |

## 三、明确**不申请**的权限（审核关注点）
| 权限 | 不申请理由 |
|------|------------|
| `webRequestBlocking` | MV3 已弃用阻塞式拦截，改用声明式 DNR，无需此权限 |
| `tabs`（读取页面内容） | 除隐藏广告元素外不读取页面文本、不采集浏览历史；popup 仅通过 `activeTab` 取当前域名 |
| `declarativeNetRequestFeedback` / `onRuleMatchedDebug` | 仅 unpacked(dev) 扩展可用，商店安装版不可用，故不申请；统计改用 `webRequest.onErrorOccurred` |
| 读取表单 / Cookie / 历史记录 | 与广告拦截用途无关，一律不申请 |

> **工程反馈（v0.1.1 修订）**：PRD 7.7 / 11.1 原要求「禁止静态声明 `<all_urls>`，改动态 host 授权」。经实现验证，全覆盖拦截 + 内容脚本注入必然要求所有站点访问权，完全动态授权会导致每站点需用户确认，与「小众工具 + 全覆盖」定位冲突。因此采用**静态声明 + 权限理由说明**方案（Chrome 商店对广告拦截类扩展的通行做法），建议同步修订 PRD 7.7 / 11.1 条款。备选方案为 `optional_host_permissions` + `chrome.scripting.registerContentScripts` 动态注册，留待后续版本评估。

## 四、数据传输声明（与隐私政策一致）
- 核心拦截**完全本地**完成，不上传任何网页 URL、页面内容或个人信息。
- 可选的匿名统计**默认开启、可一键关闭**，仅上报聚合、去标识化指标（详见 `privacy-policy.md` 第 2、3 节），经 HTTPS 传输。
- 商店审核可据此验证：关闭统计后无任何外发请求。

## 五、商店商品描述（简短版，可直接粘贴）
> CleanView 是一款轻量、隐私友好的广告拦截扩展，支持拦截展示广告、弹窗、信息流广告与视频贴片广告。
> - 拦截规则在**本地**匹配，不上传您的浏览记录；
> - 提供站点白名单，一键暂停某个网站；
> - 可选的匿名效果统计，默认开启、随时可关闭；
> - 测试期间免费使用。
