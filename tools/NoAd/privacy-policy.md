# 隐私政策（CleanView 广告拦截浏览器扩展）

> 版本：v1.0（草案） ｜ 生效日期：待定（上线前确认） ｜ 适用范围：本扩展在 Chrome / Firefox / Edge 等浏览器的各发行版本
> 说明：本文件为上架审核用草案，其中带 `【待填】` 标记的字段需在提交商店前补齐。

## 1. 概述
本政策说明 CleanView 广告拦截扩展（以下简称"本扩展"）如何收集、使用、存储与保护信息。我们的设计原则是**本地优先、最小化、可关闭**：核心广告拦截功能完全在您的设备本地完成，不依赖上传您的浏览内容。

## 2. 我们收集的信息（仅匿名统计，且可关闭）
本扩展提供一个可选的"匿名统计"功能，**默认开启，您可随时在设置中一键关闭**；关闭后本扩展不会向任何服务器发送任何数据。

开启时，我们**仅**收集以下**聚合、去标识化**的指标：

| 字段 | 说明 | 是否含个人信息 |
|------|------|----------------|
| 随机设备标识（device_id） | 安装时本地随机生成，可重置，与您的真实身份无关 | 否 |
| 日期 | 上报日期 | 否 |
| 当日拦截总数 | 当日成功拦截的广告请求/元素计数（聚合） | 否 |
| Top 被拦域名（聚合） | 被拦截次数最多的前若干域名及其计数，**不含完整网页地址** | 否 |
| 规则命中分布 | 各规则列表的命中占比（聚合） | 否 |
| 扩展版本 | 当前版本号 | 否 |

## 3. 我们明确**不收集**的信息
为避免歧义，本扩展承诺**绝不收集**以下数据：
- 您浏览的**完整网页地址（URL）**、搜索词、页面文本内容；
- 任何能识别您个人的信息（姓名、手机号、邮箱、账号、精确地理位置、设备序列号等）；
- 您在网页表单中输入的密码、信用卡号等敏感字段；
- 您在非广告场景下的正常浏览行为明细。

## 4. 我们如何收集与传输
- 统计数据通过 **HTTPS 加密传输**；
- 上报频率为**每日一次聚合上报**，不进行实时或高频上报；
- 若上报失败，本扩展会**静默丢弃**该次数据，不影响正常使用，也不会反复重试。

## 5. 数据存储与留存
- 原始上报日志在服务端**最短留存、最迟不超过 30 日**后清理，仅保留聚合统计结果；
- 不对原始日志做用户维度的长期关联分析；
- 您通过"重置标识"生成新 device_id 后，新旧标识**不可关联**，历史聚合数据无法回溯至新标识。

## 6. 您拥有的权利
- **关闭统计**：在扩展设置中一键关闭，关闭后立即停止所有上报；
- **重置标识**：在设置中重置随机设备标识，切断与历史数据的关联；
- **知情**：首次运行时本扩展会以弹窗明示上述统计内容与关闭方式（告知同意），未经提示不默认采集。

## 7. 我们不会做的事
- 不会出售、出租或共享任何数据给第三方用于营销；
- 不会将统计数据用于识别或定位个人；
- 本期统计后端部署于合规区域，**不涉及个人信息跨境传输**；如后续业务涉及跨境，将另行更新本政策并重新征得同意。

## 8. 儿童隐私
本扩展不针对儿童设计，也不会故意收集儿童的个人信息。如发现误用情况，可通过下方联系方式要求我们删除相关数据。

## 9. 政策变更
本政策如有变更，将在扩展更新说明或产品页面中告知。涉及统计范围扩大的变更，将重新征得您的明示同意。
