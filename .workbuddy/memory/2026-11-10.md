# 2026-11-10

## app 发布页改为三 Tab 设置
- 文件：`app/lib/pages/upload/upload_page.dart`（原单页长表单 → Tab 分区）
- 结构（用户确认的方案）：顶部视频预览常驻；下方三等分 Tab「视频 / 封面 / 配乐」；底部发布按钮常驻。
  - 视频 Tab：选择/追加视频、拖动排序队列、标题、描述、格式提示。
  - 封面 Tab：当前设置对象切换 chips（多视频场景）、上传封面、使用当前预览画面、选帧说明。
  - 配乐 Tab：音乐名称输入、实时显示/清除、说明文字。
  - 标题、描述归入视频 Tab；切 Tab 会收起键盘；各 Tab 输入框共用 State 中的 TextEditingController，切换不丢内容。
- 范围决策：配乐只做 UI 拆分，**不扩展后端**。`POST /api/videos` 当前仅收 `musicName`（见 `app/lib/core/api_client.dart`），不混音、不支持上传音频文件；配乐/标题/描述对本次全部视频生效，封面按视频独立。
- Tab 样式沿用项目既有下划线风格（`profile_page.dart` 的 `_ProfileTab`），新增私有组件 `_UploadTab`。
- 验证：`dart analyze lib/pages/upload/upload_page.dart` 无问题；`flutter build web --no-pub --release` 通过（46s）。
- 注意：`ChoiceChip.side` 类型是 `BorderSide?` 不是 `Border`；Dart 3.11 下 `(_, __)` 会触发 `unnecessary_underscores` 提示，用 `(_, _)`。
